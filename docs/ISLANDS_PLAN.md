# Islands 2–6 and the Lantern Café hub (owner request 2026-10-27)

Every new island has **its own puzzle game** (30 levels, verified by a solver, rising
difficulty) **and its own merge location** (new item chains, characters and story chapters, in
the style of the Lantern Café / Gossip Harbor). The **Lantern Café is the hub**: café tasks
unlock the next island; finishing an island's 30 levels unlocks the next café chapter.

| # | Island | Puzzle game | Merge location (chains · cast) |
|---|---|---|---|
| 1 | Verdant Isle (done) | rotate channels, water to saplings | Lantern Café (coffee, bakery, catch, garden) |
| 2 | Ember Reef | **sliding rows/columns** of channel blocks (wrap-around) | Reef Grill (grill, seaweed, smoothies, shells) |
| 3 | Lantern Bay | **mirrors & light**: aim lumen beams onto crystals | Lighthouse Workshop (glass, candles, lamps, maps) |
| 4 | Stone Steps | **Sokoban**: push boulders to dam/route water | Terrace Tea House (tea, pottery, dumplings, stones) |
| 5 | Rope Isles | **bridges (Hashi)**: connect islets with 1–2 bridges | Rope Market (ropes, sails, fruit, woven goods) |
| 6 | Moon Grove | **match-3** with restoration goals | Moonlight Bakery (sweets, moonflowers, lanterns) |

## Flow
level 30 (Verdant) → Lantern Café ch. 1 → its last task "Charter a boat" unlocks Ember Reef →
Ember Reef levels 1–30 → unlocks café ch. 2 **and** Reef Grill → … repeat for each island.
Each island's merge location runs on its own board/state (`save["merge_loc"][id]`); energy,
coins and gems stay per location in phase 1 (shared wallet is a later option).

## Engineering rules (per island)
- Pure rules class + solver/validator (`scripts/<game>/`), levels as JSON in
  `resources/islands/<island>/levels`, generated by a Godot tool with the real rules and checked
  in CI (initial state unsolved, stored solution solves it, par ≥ the target difficulty).
- Screen reuses the gameplay chrome (header, objectives, dock with Undo/Reset/Hint).
- Tests: rules unit tests, every level solvable, integration test through real input.
